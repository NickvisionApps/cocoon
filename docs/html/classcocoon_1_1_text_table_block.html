Detailed Description

C++ handle for the Objective-C class NSTextTableBlock (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from TextBlock.

Example
#include <cocoon.h>
cocoon::TextTableBlock text_table_block;
