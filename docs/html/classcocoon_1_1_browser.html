Detailed Description

C++ handle for the Objective-C class NSBrowser (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Control.

#include <cocoon.h>
cocoon::Browser browser;
browser.set_allows_branch_selection(true);
browser.create_rows_for_column_in_matrix().connect([](auto&&...) {});
