Detailed Description

C++ handle for the Objective-C class NSValueTransformer (Foundation).

An abstract class used to transform values from one representation to another. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::ValueTransformer value_transformer;
