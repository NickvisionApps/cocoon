Detailed Description

C++ handle for the Objective-C class NSCollectionLayoutSupplementaryItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CollectionLayoutItem.

Example
#include <cocoon.h>
cocoon::CollectionLayoutSupplementaryItem collection_layout_supplementary_item(nullptr); // null handle; instances normally come from other API calls
collection_layout_supplementary_item.set_z_index(1);
