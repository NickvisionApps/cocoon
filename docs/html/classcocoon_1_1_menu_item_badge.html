Detailed Description

C++ handle for the Objective-C class NSMenuItemBadge (AppKit).

A badge used to provide additional quantitative information specific to the menu item, such as the number of available updates. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::MenuItemBadge menu_item_badge{1};
