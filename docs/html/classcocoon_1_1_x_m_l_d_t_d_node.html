Detailed Description

C++ handle for the Objective-C class NSXMLDTDNode (Foundation).

The nodes that are exclusive to a DTD. Every DTD node has a name. Object value is defined as follows: - Entity declaration - the string that that entity resolves to eg '<' - Attribute declaration - the default value, if any - Element declaration - the validation string - Notation declaration - no objectValue Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from XMLNode.

Example
#include <cocoon.h>
cocoon::XMLDTDNode xmldtd_node;
xmldtd_node.set_dtd_kind(cocoon::XMLDTDNodeKind::EntityGeneralKind);
