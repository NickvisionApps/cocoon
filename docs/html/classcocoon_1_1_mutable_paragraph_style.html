Detailed Description

C++ handle for the Objective-C class NSMutableParagraphStyle (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ParagraphStyle.

Example
#include <cocoon.h>
cocoon::MutableParagraphStyle mutable_paragraph_style;
mutable_paragraph_style.set_alignment(cocoon::TextAlignment::Left);

◆ allows_default_tightening_for_truncation()

bool cocoon::MutableParagraphStyle::allows_default_tightening_for_truncation ( ) const

Returns the allowsDefaultTighteningForTruncation property of NSMutableParagraphStyle.

A Boolean value that indicates whether the system tightens intercharacter spacing before truncating text. When this property is set to <doc://com.apple.documentation/documentation/swift/true>, the system tries to reduce the space between characters before truncating characters. The system performs this tightening in cases where the text would not otherwise fit in the available space. The maximum amount of tightening performed by the system is dependent on the font, line width, and other factors. The default value of this property is <doc://com.apple.documentation/documentation/swift/false>.

Returns
The converted Objective-C result.

◆ hyphenation_factor()

float cocoon::MutableParagraphStyle::hyphenation_factor ( ) const

Returns the hyphenationFactor property of NSMutableParagraphStyle.

The paragraph's threshold for hyphenation. Valid values lie between '0.0' and '1.0' inclusive. The default value is '0.0'. Hyphenation is attempted when the ratio of the text width (as broken without hyphenation) to the width of the line fragment is less than the hyphenation factor. When the paragraph's hyphenation factor is '0.0', the text layout manager's hyphenation factor is used instead. When both are '0.0', hyphenation is disabled. This property detects the user-selected language by examining the first item in 'preferredLanguages'. ## See Also - <doc://com.apple.documentation/documentation/coretext/kCTLanguageAttributeName>

Returns
The converted Objective-C result.

◆ line_break_strategy()

LineBreakStrategy cocoon::MutableParagraphStyle::line_break_strategy ( ) const

Returns the lineBreakStrategy property of NSMutableParagraphStyle.

The strategies that the text system may use to break lines while laying out the paragraph. Line-break strategies are collections of options the system uses to determine where to break lines in a paragraph. This is different from ''NSParagraphStyle/lineBreakMode'', which controls how to lay out lines of text that don't fit in a container. The system ignores this property if the paragraph style's ''NSParagraphStyle/lineBreakMode'' property specifies a mode that doesn't support multiple lines, such as ''NSLineBreakMode/byClipping''. The default value is ''NSLineBreakStrategy/NSLineBreakStrategyNone''.

The paragraph's maximum line height. This property contains the maximum height in points that any line in the receiver will occupy, regardless of the font size or size of any attached graphic. This value is always nonnegative. The default value is '0'. Glyphs and graphics exceeding this height will overlap neighboring lines; however, a maximum height of '0' implies no line height limit. ◆ set_tightening_factor_for_truncation()

void cocoon::MutableParagraphStyle::set_tightening_factor_for_truncation ( float value) const

Sets the tighteningFactorForTruncation property of NSMutableParagraphStyle.

The threshold for using tightening as an alternative to truncation. When the line break mode specifies truncation, the text system will attempt to tighten inter-character spacing as an alternative to truncation, provided that the ratio of the text width to the line fragment width does not exceed '1.0 + tighteningFactorForTruncation'. Otherwise the text will be truncated at a location determined by the line break mode. The default value is '0.0' for apps linked against 10.11 and later SDK. This property is ignored when ''allowsDefaultTighteningForTruncation'' is 'true'. Explicitly setting this property to '0.0' has a side effect of also setting ''allowsDefaultTighteningForTruncation'' to 'false'.
