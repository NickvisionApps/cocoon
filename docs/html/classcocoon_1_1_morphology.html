Detailed Description

C++ handle for the Objective-C class NSMorphology (Foundation).

A description of the grammatical properties of a string. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::Morphology morphology;
morphology.set_definiteness(cocoon::GrammaticalDefiniteness::NotSet);
