Detailed Description

C++ handle for the Objective-C class NSTextListElement (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from TextParagraph.

Example
#include <cocoon.h>
cocoon::TextListElement text_list_element;
