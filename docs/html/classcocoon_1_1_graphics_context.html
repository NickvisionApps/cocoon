Detailed Description

C++ handle for the Objective-C class NSGraphicsContext (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::GraphicsContext graphics_context;
graphics_context.set_color_rendering_intent(cocoon::ColorRenderingIntent::Default);

◆ is_flipped()

bool cocoon::GraphicsContext::is_flipped ( ) const

Returns the flipped property of NSGraphicsContext.

Returns the flip state of the receiver. The state is determined by messaging -isFlipped to the focus view in the context. If no view has focus, returns NO unless the receiver is instantiated via graphicsContextWithGraphicsPort:drawingToScreen:flipped: with initialFlippedState == YES.
