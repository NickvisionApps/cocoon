Detailed Description

C++ handle for the Objective-C class NSTintConfiguration (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::TintConfiguration tint_configuration;

Returns the adaptsToUserAccentColor property of NSTintConfiguration.

If YES, the tint configuration alters its effect based on the user's preferred Accent Color. Otherwise, the tint configuration produces a constant effect regardless of the Accent Color preference.
