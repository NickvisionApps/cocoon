Detailed Description

C++ handle for the Objective-C class NSTableViewRowAction (AppKit).

An array of this class should be returned from the NSTableView delegate method tableView:rowActionsForRow:edge:. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::TableViewRowAction table_view_row_action;
table_view_row_action.set_background_color(cocoon::Color());
