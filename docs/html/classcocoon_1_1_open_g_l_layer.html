Detailed Description

C++ handle for the Objective-C class NSOpenGLLayer (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CAOpenGLLayer.

Example
#include <cocoon.h>
cocoon::OpenGLLayer open_gl_layer;
open_gl_layer.set_open_gl_context(cocoon::OpenGLContext());

Calls -[NSOpenGLLayer openGLPixelFormatForDisplayMask:].

Invoked by AppKit to ask for the pixel format to use. Should return an autoreleased NSOpenGLPixelFormat suitable for the displays specified by "mask". (In practice, this means including an NSOpenGLPFAScreenMask specification in the pixel format attribute list that's used to instantiate the NSOpenGLPixelFormat.)
