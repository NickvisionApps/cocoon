Detailed Description

C++ handle for the Objective-C class NSISO8601DateFormatter (Foundation).

A formatter that converts between dates and their ISO 8601 string representations. The ''ISO8601DateFormatter'' class generates and parses string representations of dates following the ISO 8601 standard. Use this class to create ISO 8601 representations of dates and create dates from text strings in ISO 8601 format. > Tip: > In Swift, you can use ''Date/ISO8601FormatStyle'' rather than ''ISO8601DateFormatter''. The ''FormatStyle'' API offers a declarative idiom for customizing the formatting of various types. Also, Foundation caches identical ''FormatStyle'' instances, so you don't need to pass them around your app, or risk wasting memory with duplicate formatters. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Formatter.

Example
#include <cocoon.h>
cocoon::ISO8601DateFormatter iso8601_date_formatter;
iso8601_date_formatter.set_format_options(cocoon::ISO8601DateFormatOptions::Year);
