Detailed Description

C++ handle for the Objective-C class NSWindowTab (AppKit).

This class encapsulates all the state and properties for a window when it exists in a tabbed window environment. See [NSWindow allowsAutomaticWindowTabbing] and [NSWindow tabbingIdentifier]. These properties can be set at anytime, but will only take effect when the window is shown in a tab. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::WindowTab window_tab;
window_tab.set_accessory_view(cocoon::View());

View cocoon::WindowTab::accessory_view ( ) const

Returns the accessoryView property of NSWindowTab.

Get and set the accessory view for this window when it is in a tabbed window. translatesAutoresizingMaskIntoConstraints will automatically be set to NO on the view. Constraints can be created and activated to specify the view's width and height values. A constraint will automatically be added to y-center the view, and to right align the view.

◆ attributed_title()

AttributedString cocoon::WindowTab::attributed_title ( ) const

Returns the attributedTitle property of NSWindowTab.

The attributed string tab title for this window when in a tab. This value is only used when non-nil; otherwise the title is used. The attributedTitle will use the provided attributes that are explicitly given. Attributes not given, such as the font type, color and size, will default to the correct values for the window tab.
