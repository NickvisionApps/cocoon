Detailed Description

C++ handle for the Objective-C class NSViewAnimation (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Animation.

Example
#include <cocoon.h>
cocoon::ViewAnimation view_animation;
