Detailed Description

C++ handle for the Objective-C class NSMachPort (Foundation).

A port that can be used as an endpoint for distributed object connections (or raw messaging). ''NSMachPort'' is a subclass of ''NSPort'' that wraps a Mach port, the fundamental communication port in macOS. ''NSMachPort'' allows for local (on the same machine) communication only. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Port.

Example
#include <cocoon.h>
cocoon::MachPort mach_port;
