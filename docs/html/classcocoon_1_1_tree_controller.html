Detailed Description

C++ handle for the Objective-C class NSTreeController (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ObjectController.

Example
#include <cocoon.h>
cocoon::TreeController tree_controller;
tree_controller.set_always_uses_multiple_values_marker(true);
