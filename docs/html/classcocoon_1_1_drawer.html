Detailed Description

C++ handle for the Objective-C class NSDrawer (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Responder.

Example
#include <cocoon.h>
cocoon::Drawer drawer;
drawer.set_content_size({100, 100});
