Detailed Description

C++ handle for the Objective-C class NSScrubberLayout (AppKit).

@class NSScrubberLayout @abstract @c NSScrubberLayout is an abstract class that describes the layout of items within a @c NSScrubber control. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::ScrubberLayout scrubber_layout;
