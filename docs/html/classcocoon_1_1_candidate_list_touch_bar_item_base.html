Detailed Description

C++ handle for the Objective-C class NSCandidateListTouchBarItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from TouchBarItem. Use the typed template CandidateListTouchBarItem to supply CandidateType.

Example
#include <cocoon.h>
cocoon::CandidateListTouchBarItemBase candidate_list_touch_bar_item_base(nullptr); // null handle; instances normally come from other API calls
candidate_list_touch_bar_item_base.set_allows_collapsing(true);
candidate_list_touch_bar_item_base.begin_selecting_candidate_at_index().connect([](auto&&...) {});
