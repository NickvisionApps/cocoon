Detailed Description

C++ handle for the Objective-C class NSCalendarDate (Foundation).

A specialized date object with embedded calendar information. @DeprecationSummary { Use ''NSDate'' and ''NSCalendar'' instead. } Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Date.

Example
#include <cocoon.h>
cocoon::CalendarDate calendar_date;
