Detailed Description

C++ handle for the Objective-C class NSRefreshController (AppKit).

A controller that provides pull-to-refresh functionality for scroll views. 'NSRefreshController' enables users to trigger refresh operations by pulling down on scrollable content. Add a refresh controller to an 'NSScrollView' to provide this functionality. Configure the target and action to handle refresh events. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::RefreshController refresh_controller;
refresh_controller.set_action("text");

◆ begin_refreshing()

void cocoon::RefreshController::begin_refreshing ( ) const

Calls -[NSRefreshController beginRefreshing].

Tells the refresh controller that a refresh operation has begun. Call this method to programmatically start a refresh operation. The refresh controller enters the refreshing state and displays its activity indicator. This is typically used when you want to show a refresh initiated by something other than user interaction.

◆ end_refreshing()

void cocoon::RefreshController::end_refreshing ( ) const

Calls -[NSRefreshController endRefreshing].

Tells the refresh controller that a refresh operation has ended. Call this method when your refresh operation completes. The refresh controller returns to its default appearance and exits the refreshing state.

bool cocoon::RefreshController::is_refreshing ( ) const

Returns the isRefreshing property of NSRefreshController.

A Boolean value indicating whether a refresh operation is in progress. The default value of this property is 'NO'. When the user triggers a refresh, this property automatically becomes 'YES'. Call ''endRefreshing'' when your refresh operation completes to reset this property to 'NO'.
