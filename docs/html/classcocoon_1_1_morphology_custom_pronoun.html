Detailed Description

C++ handle for the Objective-C class NSMorphologyCustomPronoun (Foundation).

A custom pronoun behavior for use in a specific language. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::MorphologyCustomPronoun morphology_custom_pronoun;
morphology_custom_pronoun.set_object_form("text");
