Detailed Description

C++ handle for the Objective-C class NSConditionLock (Foundation).

A lock that can be associated with specific, user-defined conditions. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::ConditionLock condition_lock;
condition_lock.set_name("text");
