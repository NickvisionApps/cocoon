Detailed Description

C++ handle for the Objective-C class NSButtonCell (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ActionCell.

Example
#include <cocoon.h>
cocoon::ButtonCell button_cell;
button_cell.set_alternate_image(cocoon::Image());
