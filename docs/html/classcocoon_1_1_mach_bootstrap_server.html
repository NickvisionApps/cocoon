Detailed Description

C++ handle for the Objective-C class NSMachBootstrapServer (Foundation).

@DeprecationSummary { Use ''NSXPCConnection'' instead. } A port name server that takes and returns Mach port objects. Port removal functionality is not supported in ''NSMachBootstrapServer''; if you want to cancel a service, you have to destroy the port (invalidate the ''NSMachPort'' given to ''registerPort:name:''). Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from PortNameServer.

Example
#include <cocoon.h>
cocoon::MachBootstrapServer mach_bootstrap_server;
