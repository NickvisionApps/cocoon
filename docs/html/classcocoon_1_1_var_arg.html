Detailed Description

One argument of a C-style variadic Objective-C call (for example a format string argument).

Used by the generated variadic templates such as Predicate::predicate_with_format. Numbers pass by value, std::string and handles pass as objects (%@), and const char* passes as a C string (s).

Example
cocoon::Predicate p = cocoon::Predicate::predicate_with_format("name == %@ AND age > %d", std::string("Ada"), 36);
