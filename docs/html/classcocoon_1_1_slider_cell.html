Detailed Description

C++ handle for the Objective-C class NSSliderCell (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ActionCell.

Example
#include <cocoon.h>
cocoon::SliderCell slider_cell;
slider_cell.set_allows_tick_mark_values_only(true);
