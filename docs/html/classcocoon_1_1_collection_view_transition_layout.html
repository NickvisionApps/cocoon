Detailed Description

C++ handle for the Objective-C class NSCollectionViewTransitionLayout (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CollectionViewLayout.

Example
#include <cocoon.h>
cocoon::CollectionViewTransitionLayout collection_view_transition_layout;
collection_view_transition_layout.set_transition_progress(1);
