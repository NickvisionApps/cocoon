Detailed Description

C++ handle for the Objective-C class NSPopUpButtonCell (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from MenuItemCell.

Example
#include <cocoon.h>
cocoon::PopUpButtonCell pop_up_button_cell;
pop_up_button_cell.set_alters_state_of_selected_item(true);
