Detailed Description

C++ handle for the Objective-C class NSCustomImageRep (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ImageRep.

Example
#include <cocoon.h>
cocoon::CustomImageRep custom_image_rep;
