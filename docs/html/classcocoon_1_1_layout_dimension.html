Detailed Description

C++ handle for the Objective-C class NSLayoutDimension (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from LayoutAnchorBase.

Example
#include <cocoon.h>
cocoon::LayoutDimension layout_dimension;
cocoon::LayoutDimension
