Detailed Description

C++ handle for the Objective-C class NSItemBadge (AppKit).

'NSItemBadge' represents a badge that can be attached to an 'NSToolbarItem'. This badge provides a way to display small visual indicators, such as counts and text labels, within a toolbar item. Badges can be used to highlight important information, such as unread notifications or status indicators. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::ItemBadge item_badge;
