Detailed Description

C++ handle for the Objective-C class NSMeasurement (Foundation).

A numeric quantity labeled with a unit of measure, with support for unit conversion and unit-aware calculations. An ''NSMeasurement'' object represents a quantity and unit of measure. The ''NSMeasurement'' class provides a programmatic interface to converting measurements into different units, as well as calculating the sum or difference between two measurements. ''NSMeasurement'' objects are initialized with an ''Unit'' object and 'double' value. ''NSMeasurement'' objects are immutable, and cannot be changed after being created. You can use the ''MeasurementFormatter'' class to create localized string representations of ''NSMeasurement'' objects. > Important: > The Swift overlay to the Foundation framework provides the ''Measurement'' structure, which bridges to the ''NSMeasurement'' class. For more information about value types, see <doc://com.apple.documentation/documentation/swift/working-with-foundation-types>. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Use the typed template Measurement to supply UnitType.

Example
#include <cocoon.h>
cocoon::MeasurementBase measurement_base(nullptr); // null handle; instances normally come from other API calls
