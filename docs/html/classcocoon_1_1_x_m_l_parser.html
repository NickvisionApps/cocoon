Detailed Description

C++ handle for the Objective-C class NSXMLParser (Foundation).

An event driven parser of XML documents (including DTD declarations). An ''XMLParser'' notifies its delegate about the items (elements, attributes, CDATA blocks, comments, and so on) that it encounters as it processes an XML document. It does not itself do anything with those parsed items except report them. It also reports parsing errors. For convenience, an ''XMLParser'' object in the following descriptions is sometimes referred to as a parser object. Unless used in a callback, the ''XMLParser'' is a thread-safe class as long as any given instance is only used in one thread. > Note: > Namespace support was implemented in ''XMLParser'' starting in macOS 10.4. Namespace-related methods of ''XMLParser'' prior to this version have no effect. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::XMLParser xml_parser;
xml_parser.parser_did_start_document().connect([](auto&&...) {});

◆ set_should_resolve_external_entities()

void cocoon::XMLParser::set_should_resolve_external_entities ( bool value) const

Sets the shouldResolveExternalEntities property of NSXMLParser.

A Boolean value that determines whether the parser reports declarations of external entities. 'YES' if the parser reports declarations of external entities, 'NO' otherwise. The default value is 'NO'. If you set this property to 'YES', you may cause other I/O operations, either network-based or disk-based, to load the external DTD. Toggles between disabling external entities entirely, and the current setting of the 'externalEntityResolvingPolicy'. The 'externalEntityResolvingPolicy' property should be used instead of this, unless targeting 10.9/7.0 or earlier.

valueArgument converted to the Objective-C parameter of the same role.

bool cocoon::XMLParser::should_resolve_external_entities ( ) const

Returns the shouldResolveExternalEntities property of NSXMLParser.

A Boolean value that determines whether the parser reports declarations of external entities. 'YES' if the parser reports declarations of external entities, 'NO' otherwise. The default value is 'NO'. If you set this property to 'YES', you may cause other I/O operations, either network-based or disk-based, to load the external DTD. Toggles between disabling external entities entirely, and the current setting of the 'externalEntityResolvingPolicy'. The 'externalEntityResolvingPolicy' property should be used instead of this, unless targeting 10.9/7.0 or earlier.
