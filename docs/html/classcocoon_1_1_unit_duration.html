Detailed Description

C++ handle for the Objective-C class NSUnitDuration (Foundation).

A unit of measure for a duration of time. You typically use instances of ''NSUnitDuration'' to represent specific quantities of planar angle using the ''NSMeasurement'' class. ### Duration Duration is a quantity of time. The SI unit for time is the second (sec), which is defined in terms of the radioactivity of a cesium-133 atom. Duration is also commonly expressed in terms of minutes (min) and hours (hr). > Note: > Use the ''NSDateComponents'' class to represent quantities of calendrical units, such as days, weeks, months, and years. The ''NSUnitDuration'' class defines its ''Dimension/baseUnit()'' as ''seconds'', and provides the following units, which ''UnitConverterLinear'' converters initialize with the given coefficients: | Name | Method | Symbol | Coefficient | |—|—|—|—| | Seconds | ''seconds'' | sec | '1' | | Minutes | ''minutes'' | min | '60' | | Hours | ''hours'' | hr | '3600' | Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Dimension.

Example
#include <cocoon.h>
cocoon::UnitDuration unit_duration(nullptr); // null handle; instances normally come from other API calls
