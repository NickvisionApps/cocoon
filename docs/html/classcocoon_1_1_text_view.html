Detailed Description

C++ handle for the Objective-C class NSTextView (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Text.

Example
#include <cocoon.h>
cocoon::TextView text_view;
text_view.set_accepts_glyph_info(true);
text_view.clicked_on_cell_in_rect_at_index().connect([](auto&&...) {});
