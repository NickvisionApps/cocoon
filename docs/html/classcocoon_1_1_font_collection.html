Detailed Description

C++ handle for the Objective-C class NSFontCollection (AppKit).

NSFontCollection - immutable font list Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::FontCollection font_collection;
