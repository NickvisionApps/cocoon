Detailed Description

C++ handle for the Objective-C class NSCachedURLResponse (Foundation).

A cached response to a URL request. A ''CachedURLResponse'' object provides the server's response metadata in the form of a ''URLResponse'' object, along with an NSData object containing the actual cached content data. Its storage policy determines whether the response should be cached on disk, in memory, or not at all. Cached responses also contain a user info dictionary where you can store app-specific information about the cached item. The ''URLCache'' class stores and retrieves instances of ''CachedURLResponse''. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::CachedURLResponse cached_url_response;
