Detailed Description

C++ handle for the Objective-C class NSPresentationIntent (Foundation).

A type that contains the Markdown formatting for blocks of text, like paragraphs, lists, code blocks, and parts of tables. An ''NSPresentationIntent'' object stores the Markdown semantics for a range of characters in an attributed string. When parsing Markdown into an attributed string, the system sets the value of the ''NSAttributedString/Key/presentationIntentAttributeName'' attribute to an instance of this class. When displaying your string in system views, the system applies a default visual style to match the corresponding information in this type. To replace the system's default formatting, remove these attributes from your attributed string and apply the formatting you want. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::PresentationIntent presentation_intent(nullptr); // null handle; instances normally come from other API calls
