Detailed Description

C++ handle for the Objective-C class NSTextSelectionManager (AppKit).

An object that coordinates text selection behavior for custom text views. ''NSTextSelectionManager'' provides a centralized way to manage text selection interactions using a set of gesture recognizers. For keyboard-based selection, integrate ''NSTextSelectionNavigation'' with your view. The selection manager works with a delegate to update and respond to selection changes, and with a data source to query the text layout system. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::TextSelectionManager text_selection_manager;
text_selection_manager.set_text_selection_mode(cocoon::TextSelectionMode::Editable);
text_selection_manager.selection_manager_will_begin_selection().connect([](auto&&...) {});
