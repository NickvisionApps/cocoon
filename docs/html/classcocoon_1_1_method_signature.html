Detailed Description

C++ handle for the Objective-C class NSMethodSignature (Foundation).

A record of the type information for the return value and parameters of a method. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::MethodSignature method_signature;
