Detailed Description

C++ handle for the Objective-C class NSException (Foundation).

An object that represents a special condition that interrupts the normal flow of program execution. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::Exception exception;
