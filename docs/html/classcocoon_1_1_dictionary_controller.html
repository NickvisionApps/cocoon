Detailed Description

C++ handle for the Objective-C class NSDictionaryController (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ArrayController.

Example
#include <cocoon.h>
cocoon::DictionaryController dictionary_controller;
dictionary_controller.set_excluded_keys({"a", "b"});
