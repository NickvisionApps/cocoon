Detailed Description

C++ handle for the Objective-C class NSMetadataQueryResultGroup (Foundation).

The 'NSMetadataQueryResultGroup' class represents a collection of grouped attribute results returned by an ''NSMetadataQuery'' object. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::MetadataQueryResultGroup metadata_query_result_group;
