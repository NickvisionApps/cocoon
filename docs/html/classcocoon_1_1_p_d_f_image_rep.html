Detailed Description

C++ handle for the Objective-C class NSPDFImageRep (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ImageRep.

Example
#include <cocoon.h>
cocoon::PDFImageRep pdf_image_rep;
pdf_image_rep.set_current_page(1);
