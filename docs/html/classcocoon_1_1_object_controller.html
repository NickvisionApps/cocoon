Detailed Description

C++ handle for the Objective-C class NSObjectController (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Controller.

Example
#include <cocoon.h>
cocoon::ObjectController object_controller;
object_controller.set_automatically_prepares_content(true);
