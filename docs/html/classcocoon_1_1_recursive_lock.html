Detailed Description

C++ handle for the Objective-C class NSRecursiveLock (Foundation).

A lock that may be acquired multiple times by the same thread without causing a deadlock. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::RecursiveLock recursive_lock;
recursive_lock.set_name("text");
