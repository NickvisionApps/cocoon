Detailed Description

C++ handle for the Objective-C class NSCollectionViewFlowLayout (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CollectionViewLayout.

Example
#include <cocoon.h>
cocoon::CollectionViewFlowLayout collection_view_flow_layout;
collection_view_flow_layout.set_estimated_item_size({100, 100});
