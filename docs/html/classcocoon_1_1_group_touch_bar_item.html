Detailed Description

C++ handle for the Objective-C class NSGroupTouchBarItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from TouchBarItem.

Example
#include <cocoon.h>
cocoon::GroupTouchBarItem group_touch_bar_item(nullptr); // null handle; instances normally come from other API calls
group_touch_bar_item.set_customization_label("text");

Creates a NSGroupTouchBarItem with the appropriate settings to match system style alerts in NSTouchBar. Spacing between items is under control of the client, but in general NSTouchBarItemIdentifierFixedSpaceLarge is recommended anywhere additional spacing is required. The groupUserInterfaceLayoutDirection will be set to [NSApp userInterfaceLayoutDirection].

Creates a NSGroupTouchBarItem with the allowed compression options provided in the order AppKit defines. Default order: BreakEqualWidths, ReduceMetrics, HideText, HideImages. This should only be used with standard options provided by AppKit. Custom options need to be added using the prioritizedCompressionOptions property.

An NSTouchBar, presented seamlessly as part of the NSTouchBar this item is hosted in. The NSTouchBar may have its own principal item, and can be customized (or not) per the normal customization rules. By default this is an empty bar that cannot be customized. This property is archived.

◆ group_user_interface_layout_direction()

UserInterfaceLayoutDirection cocoon::GroupTouchBarItem::group_user_interface_layout_direction ( ) const

Returns the groupUserInterfaceLayoutDirection property of NSGroupTouchBarItem.

Get and set the user interface layout direction of the groupTouchBar, which defines the order in which the items should be laid out. By default, this value is NSUserInterfaceLayoutDirectionLeftToRight. To flip the layout direction of the group to the user’s preferred layout, this should be set to [NSApp userInterfaceLayoutDirection].
