Detailed Description

C++ handle for the Objective-C class NSExtensionItem (Foundation).

An immutable collection of values representing different aspects of an item for an extension to act upon. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::ExtensionItem extension_item;
