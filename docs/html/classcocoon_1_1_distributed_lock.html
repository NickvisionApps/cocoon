Detailed Description

C++ handle for the Objective-C class NSDistributedLock (Foundation).

A lock that multiple applications on multiple hosts can use to restrict access to some shared resource, such as a file. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::DistributedLock distributed_lock{"text"};
