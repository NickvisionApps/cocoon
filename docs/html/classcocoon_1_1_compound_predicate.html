Detailed Description

C++ handle for the Objective-C class NSCompoundPredicate (Foundation).

A specialized predicate that evaluates logical combinations of other predicates. Use ''NSCompoundPredicate'' to create an 'AND' or 'OR' compound predicate of one or more other predicates, or the 'NOT' of a single predicate. For the logical 'AND' and 'OR' operations: - An 'AND' predicate with no subpredicates evaluates to <doc://com.apple.documentation/documentation/swift/true>. - An 'OR' predicate with no subpredicates evaluates to <doc://com.apple.documentation/documentation/swift/false>. - A compound predicate with one or more subpredicates evaluates to the truth of its subpredicates. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Predicate.

Example
#include <cocoon.h>
cocoon::CompoundPredicate compound_predicate;
