Detailed Description

C++ handle for the Objective-C class NSPathControlItem (AppKit).

NSPathControlItem is used to represent an individual path segment in an NSPathControl. NSPathControlItem should not be subclassed. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::PathControlItem path_control_item;
path_control_item.set_attributed_title(cocoon::AttributedString());

The image/icon shown for this particular component along the path. The NSPathControlItem can display both an image and title. When drawing, your image will be scaled to fit the available area, which in 10.10 and earlier releases is 16x16 points for NSPathStyleStandard or NSPathStylePopUp, and 14x14 points for NSPathStyleNavigationBar.
