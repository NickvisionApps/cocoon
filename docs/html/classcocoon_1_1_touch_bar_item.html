Detailed Description

C++ handle for the Objective-C class NSTouchBarItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::TouchBarItem touch_bar_item{"text"};
touch_bar_item.set_visibility_priority(1);

bool cocoon::TouchBarItem::is_visible ( ) const

Returns the visible property of NSTouchBarItem.

When YES, this item is attached to a visible NSTouchBar, and is being displayed. Note that some types of items are never considered visible, for example spaces, other items proxys, and groups. This property is key value observable.

void cocoon::TouchBarItem::set_visibility_priority ( float value) const

Sets the visibilityPriority property of NSTouchBarItem.

If there are more items in the NSTouchBar than can be displayed, some will be hidden. Items with high visibility priority will be hidden after items with low visibility priority.
