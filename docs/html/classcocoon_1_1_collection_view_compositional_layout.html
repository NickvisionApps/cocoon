Detailed Description

C++ handle for the Objective-C class NSCollectionViewCompositionalLayout (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CollectionViewLayout.

Example
#include <cocoon.h>
cocoon::CollectionViewCompositionalLayout collection_view_compositional_layout{cocoon::CollectionLayoutSection()};
collection_view_compositional_layout.set_configuration(cocoon::CollectionViewCompositionalLayoutConfiguration());
