Detailed Description

A pop-up or pull-down menu button.

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Button.

Example
cocoon::PopUpButton popup;
popup.add_items_with_titles({"Small", "Medium", "Large"});
popup.selection_changed().connect([](std::int64_t index) {});
