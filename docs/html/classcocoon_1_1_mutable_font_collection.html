Detailed Description

C++ handle for the Objective-C class NSMutableFontCollection (AppKit).

NSMutableFontCollection - mutable font list Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from FontCollection.

Example
#include <cocoon.h>
cocoon::MutableFontCollection mutable_font_collection;
