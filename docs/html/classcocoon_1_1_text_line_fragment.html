Detailed Description

C++ handle for the Objective-C class NSTextLineFragment (AppKit).

A class that represents a line fragment as a single textual layout and rendering unit inside a text layout fragment. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::TextLineFragment text_line_fragment(nullptr); // null handle; instances normally come from other API calls
