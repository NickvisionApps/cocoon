Detailed Description

C++ handle for the Objective-C class NSTextTable (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from TextBlock.

Example
#include <cocoon.h>
cocoon::TextTable text_table;
text_table.set_collapses_borders(true);
