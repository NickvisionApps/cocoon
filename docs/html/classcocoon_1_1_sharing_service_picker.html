Detailed Description

C++ handle for the Objective-C class NSSharingServicePicker (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::SharingServicePicker sharing_service_picker(nullptr); // null handle; instances normally come from other API calls
sharing_service_picker.did_choose_sharing_service().connect([](auto&&...) {});

void cocoon::SharingServicePicker::show_relative_to_rect ( const Rect & rect,
const View & view,
RectEdge preferred_edge ) const

Calls -[NSSharingServicePicker showRelativeToRect:ofView:preferredEdge:].

Shows the picker, populated with sharing services related to the instance items. When the user selects one of the sharing services, the sharing service will be performed. Note that this method must be called on mouseDown.
