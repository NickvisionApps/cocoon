Detailed Description

C++ handle for the Objective-C class NSUserDefaultsController (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Controller.

Example
#include <cocoon.h>
cocoon::UserDefaultsController user_defaults_controller;
user_defaults_controller.set_applies_immediately(true);
