Detailed Description

C++ handle for the Objective-C class NSRotationGestureRecognizer (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from GestureRecognizer.

Example
#include <cocoon.h>
cocoon::RotationGestureRecognizer rotation_gesture_recognizer;
rotation_gesture_recognizer.set_rotation(1);
