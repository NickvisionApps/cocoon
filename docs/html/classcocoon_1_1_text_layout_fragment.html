Detailed Description

C++ handle for the Objective-C class NSTextLayoutFragment (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::TextLayoutFragment text_layout_fragment{cocoon::TextElement(), cocoon::TextRange()};
text_layout_fragment.set_layout_queue(cocoon::OperationQueue());

Returns the renderingSurfaceBounds property of NSTextLayoutFragment.

The bounds defining the area required for rendering the contents. The coordinate system is relative to ''layoutFragmentFrame''. The coordinate system is vertically flipped, meaning origin ('{0,0}') is at the upper-left corner. The size should be larger than 'layoutFragmentFrame.size'. The origin could be in the negative coordinate since the rendering could be stretched out of 'layoutFragmentFrame'. Only valid when ''state'' is greater than 'NSTextLayoutFragmentStateEstimatedUsageBounds'.

Calls -[NSTextLayoutFragment textLineFragmentForTextLocation:isUpstreamAffinity:].

Returns a text line fragment from a specific text location in the document. Set 'isUpstreamAffinity' to 'true' to find a text fragment by its element range end location, such as when you enumerate over line fragments in reverse order. Set 'isUpstreamAffinity' to 'false' to find a text fragment that contains 'textLocation'. - Parameters: - textLocation: The text location to search for. - isUpstreamAffinity: When the location is at the end of a text line fragment (and the beginning of another), 'true' chooses the one ending with the location; 'false' chooses the following. - Returns: The matching line fragment, or 'nil'.
