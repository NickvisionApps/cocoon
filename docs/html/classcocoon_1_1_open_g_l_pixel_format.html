Detailed Description

C++ handle for the Objective-C class NSOpenGLPixelFormat (AppKit).

NSOpenGLPixelFormat interface. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::OpenGLPixelFormat open_gl_pixel_format;
