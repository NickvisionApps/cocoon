Detailed Description

C++ handle for the Objective-C class NSViewCornerConfiguration (AppKit).

A configuration object that defines the corner styles of a view’s overall shape. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::ViewCornerConfiguration view_corner_configuration(nullptr); // null handle; instances normally come from other API calls
