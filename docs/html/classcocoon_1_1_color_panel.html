Detailed Description

C++ handle for the Objective-C class NSColorPanel (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Panel.

Example
#include <cocoon.h>
cocoon::ColorPanel color_panel;
color_panel.set_accessory_view(cocoon::View());
