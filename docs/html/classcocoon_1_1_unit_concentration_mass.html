Detailed Description

C++ handle for the Objective-C class NSUnitConcentrationMass (Foundation).

A unit of measure for concentration of mass. You typically use instances of ''NSUnitConcentrationMass'' to represent specific quantities of concentration using the ''NSMeasurement'' class. ### Concentration of Mass Concentration is the abundance of a constituent within a volume. Concentration can be expressed by SI derived units in terms of kilograms per cubic meter (kg/m3). The ''NSUnitConcentrationMass'' class defines its ''Dimension/baseUnit()'' as ''gramsPerLiter'', and provides the following units, which are initialized using ''UnitConverterLinear'' converters with the specified coefficients: | Name | Method | Symbol | Coefficient | |—|—|—|—| | Grams Per Liter | ''gramsPerLiter'' | g/L | '1' | | Milligrams Per Deciliter | ''milligramsPerDeciliter'' | mg/dL | '0.01' | | Millimoles Per Liter | ''millimolesPerLiter(withGramsPerMole:)'' | mmol/L | '18 gramsPerMole' | Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Dimension.
