Detailed Description

C++ handle for the Objective-C class NSCollectionLayoutDecorationItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CollectionLayoutItem.

Example
#include <cocoon.h>
cocoon::CollectionLayoutDecorationItem collection_layout_decoration_item(nullptr); // null handle; instances normally come from other API calls
collection_layout_decoration_item.set_z_index(1);
