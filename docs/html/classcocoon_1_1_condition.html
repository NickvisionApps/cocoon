Detailed Description

C++ handle for the Objective-C class NSCondition (Foundation).

A condition variable whose semantics follow those used for POSIX-style conditions. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::Condition condition;
condition.set_name("text");
