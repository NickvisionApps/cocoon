Detailed Description

C++ handle for the Objective-C class NSComboBoxCell (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from TextFieldCell.

Example
#include <cocoon.h>
cocoon::ComboBoxCell combo_box_cell;
combo_box_cell.set_button_bordered(true);
