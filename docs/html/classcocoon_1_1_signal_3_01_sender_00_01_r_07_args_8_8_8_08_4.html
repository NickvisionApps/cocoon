Detailed Description

template<class Sender, class R, class... Args>
class cocoon::Signal< Sender, R(Args...)>

A signal named on one native object; connect a callback to be notified.

Callbacks are stored on the native object, so they live exactly as long as it does. A callback may take the sender handle as its first argument, or just the signal's own arguments. Capture other handles with WeakRef to avoid retain cycles. Signals are obtained through accessor methods such as button.clicked().

Example
cocoon::Button button("Click me");
button.clicked().connect([] { }); // arguments only
button.clicked().connect([](cocoon::Button& sender) { }); // with the sender
bool wired = button.clicked().is_connected(); // true
button.clicked().disconnect();
