Detailed Description

C++ handle for the Objective-C class NSInvocationOperation (Foundation).

An operation that manages the execution of a single encapsulated task specified as an invocation. The ''NSInvocationOperation'' class is a concrete subclass of ''Operation'' that you use to initiate an operation that consists of invoking a selector on a specified object. This class implements a non-concurrent operation. For more information on concurrent versus non-concurrent operations, see ''Operation''. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Operation.

Example
#include <cocoon.h>
cocoon::InvocationOperation invocation_operation;
