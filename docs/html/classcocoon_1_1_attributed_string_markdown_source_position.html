Detailed Description

C++ handle for the Objective-C class NSAttributedStringMarkdownSourcePosition (Foundation).

The position of attributed string text in its original Markdown source string. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::AttributedStringMarkdownSourcePosition attributed_string_markdown_source_position;

Calls -[NSAttributedStringMarkdownSourcePosition rangeInString:].

Returns a range indicating the source portion within a Markdown string. Use this method to access the marked-up region of 'string' with an 'NSRange', rather than making manual calculations based on row and column values. - Parameter string: The Markdown source string that this source position object refers to. - Returns: A range that represents the source portion within a source Markdown string.
