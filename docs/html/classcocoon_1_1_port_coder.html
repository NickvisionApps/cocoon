Detailed Description

C++ handle for the Objective-C class NSPortCoder (Foundation).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Coder.

Example
#include <cocoon.h>
cocoon::PortCoder port_coder;
