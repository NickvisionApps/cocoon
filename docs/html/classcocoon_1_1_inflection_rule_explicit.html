Detailed Description

C++ handle for the Objective-C class NSInflectionRuleExplicit (Foundation).

An inflection rule that uses a morphology instance to determine how to inflect attributed strings. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from InflectionRule.

Example
#include <cocoon.h>
cocoon::InflectionRuleExplicit inflection_rule_explicit{cocoon::Morphology()};
