Detailed Description

C++ handle for the Objective-C class NSURLAuthenticationChallenge (Foundation).

A challenge from a server requiring authentication from the client. Your app receives authentication challenges in various ''URLSession'', ''NSURLConnection'', and ''NSURLDownload'' delegate methods, such as ''URLSessionTaskDelegate/urlSession(:task:didReceive:completionHandler:)''. These objects provide the information you'll need when deciding how to handle a server's request for authentication. At the core of that authentication challenge is a protection space that defines the type of authentication being requested, the host and port number, the networking protocol, and (where applicable) the authentication realm (a group of related URLs on the same server that share a single set of credentials). Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::URLAuthenticationChallenge url_authentication_challenge;

URLCredential cocoon::URLAuthenticationChallenge::proposed_credential ( ) const

Returns the proposedCredential property of NSURLAuthenticationChallenge.

The proposed credential for this challenge. The proposed credential may be 'nil', if there is no default credential to use for this challenge (either stored or in the URL). If the credential is not 'nil' and returns 'YES' for 'hasPassword', it is ready to use as-is. If it returns 'NO' for 'hasPassword', it provides a default username the client could use when prompting.
