Detailed Description

C++ handle for the Objective-C class NSAttributedStringMarkdownParsingOptions (Foundation).

Options that affect the parsing of Markdown content into an attributed string. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::AttributedStringMarkdownParsingOptions attributed_string_markdown_parsing_options;
attributed_string_markdown_parsing_options.set_allows_extended_attributes(true);
