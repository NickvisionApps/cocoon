Detailed Description

C++ handle for the Objective-C class NSTrackingSeparatorToolbarItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ToolbarItem.

Example
#include <cocoon.h>
cocoon::TrackingSeparatorToolbarItem tracking_separator_toolbar_item;
tracking_separator_toolbar_item.set_divider_index(1);
