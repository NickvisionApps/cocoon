Detailed Description

C++ handle for the Objective-C class NSTouch (AppKit).

Unlike the iPhone, NSTouch objects do not persist for the life of the touch. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::Touch touch;
