Detailed Description

C++ handle for the Objective-C class NSRelativeDateTimeFormatter (Foundation).

A formatter that creates locale-aware string representations of a relative date or time. Use the strings that the formatter produces, such as "1 hour ago", "in 2 weeks", "yesterday", and "tomorrow" as standalone strings. Embedding them in other strings may not be grammatically correct. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Formatter.

Example
#include <cocoon.h>
cocoon::RelativeDateTimeFormatter relative_date_time_formatter;
relative_date_time_formatter.set_calendar(cocoon::Calendar());

◆ localized_string_from_date_components()

std::string cocoon::RelativeDateTimeFormatter::localized_string_from_date_components ( const DateComponents & date_components) const

Calls -[NSRelativeDateTimeFormatter localizedStringFromDateComponents:].

Returns a formatted string representing a relative time from the given date components. Negative component values are evaluated as a date in the past. This method formats the value of the least granular unit in the 'NSDateComponents' object, and does not provide a compound format of the date component. Note this method only supports the following components: year, month, week of month, day, hour, minute, and second. The rest will be ignored.
