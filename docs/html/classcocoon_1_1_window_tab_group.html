Detailed Description

C++ handle for the Objective-C class NSWindowTabGroup (AppKit).

NSWindowTabGroup represents a group of windows that are shown together in one tab group. See NSWindow's tabGroup property. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::WindowTabGroup window_tab_group;
window_tab_group.set_overview_visible(true);

◆ windows()

std::vector< Window > cocoon::WindowTabGroup::windows ( ) const

Returns the windows property of NSWindowTabGroup.

Returns the entire group (stack) of windows that are all visually shown together in one virtual tabbed window and associated with this particular window tab group. Operations can then be done on each window, as necessary. For instance, iterating over each window in the group and calling performClose: will close the entire stack. The order of items in the array is the same order as the tabs visually shown (leading to trailing). This property is KVO compliant
