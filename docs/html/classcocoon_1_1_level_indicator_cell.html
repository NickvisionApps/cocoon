Detailed Description

C++ handle for the Objective-C class NSLevelIndicatorCell (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ActionCell.

Example
#include <cocoon.h>
cocoon::LevelIndicatorCell level_indicator_cell;
level_indicator_cell.set_critical_value(1);
