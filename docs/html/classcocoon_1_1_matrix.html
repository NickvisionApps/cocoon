Detailed Description

C++ handle for the Objective-C class NSMatrix (AppKit).

NSMatrix is deprecated and will be unsupported in future releases. For radio button grouping, sibling radio buttons that share the same action will operate in an exclusive mode. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Control.

#include <cocoon.h>
cocoon::Matrix matrix;
matrix.set_allows_empty_selection(true);
matrix.control_text_did_begin_editing().connect([](auto&&...) {});
