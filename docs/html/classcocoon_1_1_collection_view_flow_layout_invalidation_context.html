Detailed Description

C++ handle for the Objective-C class NSCollectionViewFlowLayoutInvalidationContext (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CollectionViewLayoutInvalidationContext.

Example
#include <cocoon.h>
cocoon::CollectionViewFlowLayoutInvalidationContext collection_view_flow_layout_invalidation_context;
collection_view_flow_layout_invalidation_context.set_invalidate_flow_layout_attributes(true);
