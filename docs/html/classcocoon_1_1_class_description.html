Detailed Description

C++ handle for the Objective-C class NSClassDescription (Foundation).

An abstract class that provides the interface for querying the relationships and properties of a class. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::ClassDescription class_description;
