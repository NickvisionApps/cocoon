Detailed Description

C++ handle for the Objective-C class NSSharingServicePickerToolbarItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ToolbarItem.

Example
#include <cocoon.h>
cocoon::SharingServicePickerToolbarItem sharing_service_picker_toolbar_item;
sharing_service_picker_toolbar_item.did_choose_sharing_service().connect([](auto&&...) {});
