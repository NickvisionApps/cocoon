Detailed Description

C++ handle for the Objective-C class NSRelativeSpecifier (Foundation).

A specifier that indicates an object in a collection by its position relative to another object. You don't normally subclass 'NSRelativeSpecifier'. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ScriptObjectSpecifier.

Example
#include <cocoon.h>
cocoon::RelativeSpecifier relative_specifier;
relative_specifier.set_base_specifier(cocoon::ScriptObjectSpecifier());
