Detailed Description

template<class T>
class cocoon::WeakRef< T >

A non-owning reference to a handle's native object that becomes null when the object dies.

Use it inside callbacks to capture a control without creating a retain cycle.

Example
cocoon::Label status("Ready");
cocoon::WeakRef<cocoon::Label> weak(status);
cocoon::Button button("Go");
button.clicked().connect([weak] {
cocoon::Label label = weak.lock();
if (label)
label.set_string_value("Done");
});
