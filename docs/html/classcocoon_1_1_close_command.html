Detailed Description

C++ handle for the Objective-C class NSCloseCommand (Foundation).

A command that closes one or more scriptable objects. An instance of 'NSCloseCommand' closes the specified scriptable object or objects—typically a document or window (and its associated document, if any). The command may optionally specify a location to save in and how to handle modified documents (by automatically saving changes, not saving them, or asking the user). 'NSCloseCommand' is part of Cocoa's built-in scripting support. It works automatically to support the 'close' command through key-value coding. Most applications don't need to subclass 'NSCloseCommand' or call its methods. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ScriptCommand.

Example
#include <cocoon.h>
cocoon::CloseCommand close_command;
