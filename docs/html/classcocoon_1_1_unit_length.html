Detailed Description

C++ handle for the Objective-C class NSUnitLength (Foundation).

A unit of measure for length. You typically use instances of ''UnitLength'' to represent specific quantities of length using the ''NSMeasurement'' class. ### Length Length is the dimensional extent of matter. The SI unit for length is the meter (m), which is defined in terms of the distance traveled by light in a vacuum.
