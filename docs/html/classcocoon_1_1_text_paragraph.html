Detailed Description

C++ handle for the Objective-C class NSTextParagraph (AppKit).

A class that represents a single paragraph backed by an attributed string as the contents. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from TextElement.

Example
#include <cocoon.h>
cocoon::TextParagraph text_paragraph;
