Detailed Description

C++ handle for the Objective-C class NSPageController (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ViewController.

Example
#include <cocoon.h>
cocoon::PageController page_controller;
page_controller.prepare_view_controller_with_object().connect([](auto&&...) {});
