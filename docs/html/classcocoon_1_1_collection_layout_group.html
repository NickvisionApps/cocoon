Detailed Description

C++ handle for the Objective-C class NSCollectionLayoutGroup (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CollectionLayoutItem.

Example
#include <cocoon.h>
cocoon::CollectionLayoutGroup collection_layout_group(nullptr); // null handle; instances normally come from other API calls
collection_layout_group.set_inter_item_spacing(cocoon::CollectionLayoutSpacing());
