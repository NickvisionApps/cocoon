Detailed Description

C++ handle for the Objective-C class NSDatePickerCell (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ActionCell.

Example
#include <cocoon.h>
cocoon::DatePickerCell date_picker_cell;
date_picker_cell.set_background_color(cocoon::Color());
date_picker_cell.validate_proposed_date_value_time_interval().connect([](auto&&...) {});
