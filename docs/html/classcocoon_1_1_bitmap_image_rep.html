Detailed Description

C++ handle for the Objective-C class NSBitmapImageRep (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ImageRep.

Example
#include <cocoon.h>
cocoon::BitmapImageRep bitmap_image_rep;
