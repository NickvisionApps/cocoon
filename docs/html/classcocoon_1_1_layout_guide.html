Detailed Description

C++ handle for the Objective-C class NSLayoutGuide (AppKit).

NSLayoutGuides will not show up in the view hierarchy, but may be used as items in an NSLayoutConstraint and represent a rectangle in the layout engine. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::LayoutGuide layout_guide;
layout_guide.set_identifier("text");
