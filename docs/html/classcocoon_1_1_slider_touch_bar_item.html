Detailed Description

C++ handle for the Objective-C class NSSliderTouchBarItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from TouchBarItem.

Example
#include <cocoon.h>
cocoon::SliderTouchBarItem slider_touch_bar_item(nullptr); // null handle; instances normally come from other API calls
slider_touch_bar_item.set_action("text");
