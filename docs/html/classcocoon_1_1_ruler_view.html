Detailed Description

C++ handle for the Objective-C class NSRulerView (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from View.

Example
#include <cocoon.h>
cocoon::RulerView ruler_view;
ruler_view.set_accessory_view(cocoon::View());
