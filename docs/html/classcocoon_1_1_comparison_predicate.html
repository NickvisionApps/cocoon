Detailed Description

C++ handle for the Objective-C class NSComparisonPredicate (Foundation).

A specialized predicate for comparing expressions. Use comparison predicates to compare the results of two expressions. You create a comparison predicate with an operator, a left expression, and a right expression, and use instances of the ''NSExpression'' class to represent those expressions. When you evaluate the predicate, it returns a 'BOOL' value as the result of invoking the operator with the results of evaluating the expressions. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from Predicate.

Example
#include <cocoon.h>
cocoon::ComparisonPredicate comparison_predicate;
