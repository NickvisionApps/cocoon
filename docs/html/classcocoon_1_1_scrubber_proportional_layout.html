Detailed Description

C++ handle for the Objective-C class NSScrubberProportionalLayout (AppKit).

@class NSScrubberProportionalLayout @abstract @c NSScrubberProportionalLayout is a concrete layout object that sizes each item to some fraction of the scrubber's visible size. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from ScrubberLayout.

Example
#include <cocoon.h>
cocoon::ScrubberProportionalLayout scrubber_proportional_layout;
scrubber_proportional_layout.set_number_of_visible_items(1);
