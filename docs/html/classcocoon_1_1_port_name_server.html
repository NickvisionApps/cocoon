Detailed Description

C++ handle for the Objective-C class NSPortNameServer (Foundation).

An object-oriented interface to the port registration service used by the distributed objects system. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::PortNameServer port_name_server;
