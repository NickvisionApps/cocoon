Detailed Description

C++ handle for the Objective-C class NSCollectionLayoutBoundarySupplementaryItem (AppKit).

Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance. Inherits from CollectionLayoutSupplementaryItem.

Example
#include <cocoon.h>
cocoon::CollectionLayoutBoundarySupplementaryItem collection_layout_boundary_supplementary_item(nullptr); // null handle; instances normally come from other API calls
collection_layout_boundary_supplementary_item.set_extends_boundary(true);
