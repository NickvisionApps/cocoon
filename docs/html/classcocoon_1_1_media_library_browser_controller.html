Detailed Description

C++ handle for the Objective-C class NSMediaLibraryBrowserController (AppKit).

@abstract This class configures and displays a media browser panel. @discussion This class provides no direct access to the panel, and its meaningful contents aren't in the calling process. Handles are cheap, copyable wrappers around a retained native object: copies refer to the same underlying instance.

Example
#include <cocoon.h>
cocoon::MediaLibraryBrowserController media_library_browser_controller;
media_library_browser_controller.set_frame({{0, 0}, {100, 100}});
